# 周代列国 · 历史对照图

纯静态中文历史对照网页，覆盖周王室与17个主要诸侯国。打开 `dist/index.html` 即可使用；部署目录为 `dist`。

前端源码维护于 `src/`，`dist/` 全部由 `node build.mjs` 生成，请勿直接修改。最新架构、模块边界及旧记录兼容说明见 [架构文档](docs/ARCHITECTURE.md)。

主要交互：横向拖动、纵向滚动、时代定位、缩放、国家筛选、国家/君主/人物/事件分类搜索、详情、同年列国对照及秦统一时期延伸。

## 数据

`data/atlas.json` 是唯一可编辑的历史资料源，包含国家、君主区间、独立人物、事件、活动、关系表与去重后的来源目录。`lib/atlas.mjs` 负责校验与生成浏览器投影；`dist/data.js` 是生成物，请勿手改。资料模型、编辑约束与校核状态见 [data/README.md](data/README.md)。

```sh
node build.mjs
node build.mjs --check
node --test tests/*.test.mjs tests/*.test.cjs
```

无需安装依赖，使用 Node.js 22 或更高版本。网页仍可直接打开 `dist/index.html`。

`sync-data.mjs` 仍可使用，现在转调完整构建；`--check` 检查所有发布成果。受限 Windows 环境若出现父目录 realpath 的 EPERM，可为 Node 添加 `--preserve-symlinks --preserve-symlinks-main`。

纪年底表参考《史记》十二诸侯年表、六国年表与现代君主列表汇编。正文包含原典来源与采用口径说明。该版重大事件为精选；西周早期、晋终结、楚破越及部分即位纪年须继续校勘。不能将元年直接等同实际即位年份。未逐项核实的君主结局明确注明。

秦统一是秦诸侯国阶段的结束，不是秦王政统治的结束。卫国到前209年才终止，不在前221年截断为灭亡。

浏览器原生 WebMCP API 可用时注册 `compare_zhou_year`；不支持时不影响界面功能。

## 第二版交互与人物资料

支持全局36–160px行高、单国行高、320–1000px视窗高度、自动适配所选国家、展开对比，以及战国七雄一键对比。国家排序支持拖动和上移/下移，布局偏好保存在浏览器中。

点击君主可查看简要生平、关键臣子与将领的身份、关联关系、简介和原典来源。当前129个在位区间有专门生平简介，78个区间关联关键人物，当前独立资料共116位人物。其余区间显示纪年与记载摘要，明确标注资料不足。搜索支持已收录人物姓名。

旧 `enrich-people.mjs` 仅作为兼容入口调用统一构建，不再补写或覆盖资料。

## 第三版：对照研究

- 自动内容密度：低于2.4px/年显示国家存续与精选关键事件，2.4–7px/年显示君主与事件摘要，7px/年以上在足够宽度与行高下显示在位年份。可手动切换完整内容或概览。
- 点击事件高亮相关国家与当年在位君主；20条重点事件收录了明确关联的人物角色，其他事件保留待核实提示，不把全体臣子当成参与者。
- 纪年分较确定、推定、存在异说；君主详情将实际即位、元年、退位/传位、去世、身份转变分开。未核实日期不从条带端点推导。牧野、马陵、楚越及部分君主的异说可展开查看。
- 预设七雄、秦魏变法、晋楚争霸、鲁卫齐；可命名保存当前国家、顺序、固定行、行高与时间范围，支持组合JSON导出导入。浏览器保存最多30组。钉住国家后该行在纵向滚动中保持可见；在排序面板中只能在同一固定状态组内上/下移动。

更新资料只需编辑 `data/atlas.json` 并运行 `node sync-data.mjs`。旧 `enrich-context.mjs` 也已改为兼容入口；不再保留脚本内的第二份历史正文。

## 搜索与快速切换

七雄组合保留在右侧快速切换栏。搜索默认匹配名称、别称和明确的事件参与人物，按国家、君主、人物、事件分组；可勾选“同时搜索简介”，简介提及会单独标注。支持常用简繁体写法与已收录别称。搜索范围可选全站或当前所选国家，全站包含未选国家与秦统一时期。点击结果会打开对应详情并调整显示范围；未定位到具体年份的君主仅展示资料，不生成虚构的时间点。

## 详情返回

国家世系、君主、人物、事件和密集事件列表之间的跳转保留浏览路径。详情顶部的返回按钮始终可见，可逐级恢复上页内容、已展开的纪年说法与阅读位置；首层详情返回时间线或搜索结果，恢复搜索、筛选、缩放、参考年份及滚动位置。Esc同样逐级返回；关闭按钮或点击背景直接回到最初入口。“定位在位起点”和“查看图上联动”是主动跳转，保留目标年份与图上联动。

## 第四版：学习笔记

- 所有已收录臣子、将领姓名可点击，搜索、君主详情和事件人物统一进入独立资料页，显示生平、活动国家、主要事迹、关联君主与事件。已整理吴起、商鞅、孙膑、乐毅、伍子胥、管仲、孔子、孟子、张仪、范蠡、范雎、李斯12人的活动轨迹；不明确的年份不推算，出身、流亡、游说与任职分开标注。孟子的游历先后需辨，李斯的帝国时期结局只在生平中补述，不产生超出图示范围的节点。
- 全部105条已收录事件含背景、经过、结果、后续影响和主题关联；这不表示已经穷尽周代事件。人物轨迹及叙事摘要统一在 `data/atlas.json` 维护，运行 `node sync-data.mjs` 编入浏览器数据。摘要附原典来源，主题线索不自动表示直接因果。丹阳、汉中、蓝田区分战役阶段，陈蔡的中断、复国与最终灭亡分开记述。勾选“同时搜索简介”后，也能检索事件四段摘要和人物轨迹；别称搜索继续默认开启。
- `dist/study.js`自动保存时间范围、缩放、筛选、参考年份、搜索、国家布局和阅读位置，刷新后恢复；保存最近50条国家/君主/人物/事件浏览记录及详情滚动位置。详情中的临时联动不会覆盖进入前的主图阅读位置。只存结构化数据和条目ID，不存详情HTML；均保存在当前浏览器，可清空浏览历史。
- `dist/export.js`按当前显示国家与可见时间范围导出。时间范围可改，每张可选择100/150/300年或全范围；输出A4横向分页PDF或ZIP内的2400×1700 PNG图片。完整君主、事件、纪年异说、图例和来源另附文字索引，避开窄条文字挤压。图上与导出中的国家中断/复国分段显示，统一事件编号跨国对应；事件类别筛选保留，内容不受缩放密度和显示模式限制。文件在浏览器生成，不依赖外部CDN。PDF为高分辨率图片页面，适合阅读打印，文字不是可选中的PDF文本。


## 第五版：关联与纪年一致性

- “孟子见梁惠王”只关联魏；孟子的齐国经历单独属于人物活动，不再改写事件国家。
- 孔子出生列出前551年与前552年系年及原典；魏惠王称王和五国相王改为“存在异说”，明确未完成校勘部分。五国相王补上魏的相关关系，注明图示国家不等于确定的五国名单，赵有拒称王而称君的记载。
- 晋悼公实际即位为前573年，图示条带沿用前572年起点；事件直接引用实际即位字段。比较与高亮纳入已核实即位年，君主详情亦能回到该事件。秦王政元年事件直接引用其元年字段。
- 纪年校核状态区分沿用资料、部分校核、本条已核对；保留旧资料的待校勘属性，不把结构迁移当作全部史实核验。
- 历史正文、关系、来源目录与前端交互解耦。所有正文保留，旧的三个 JSON 副本移出部署目录；此前版本仍在 Git 历史中。
- 27项 Node 自动化检查覆盖资料完整性、纯函数构建、引用与纪年校验、误关联回归，以及搜索、密度、联动、组合、详情返回、阅读恢复和导出数据。UI 检查采用 DOM 桩，不替代真实浏览器和移动设备验收。

## 第六版：查询、状态与输出解耦

- 历史查询统一到 `src/core/history.js`。页面对照、事件联动和浏览器查询接口共用实际即位年与国家中断规则；条带继续使用明确标注的年表口径。
- 搜索独立于页面，人物使用稳定ID；旧姓名阅读记录和搜索目标在唯一匹配时自动迁移。
- 应用状态集中管理，导航路径独立维护；阅读模型、阅读控制器与存储适配分离。损坏的缓存字段不阻止页面启动。
- 网页与导出共享对照内容模型；分页、画布绘制、PDF/ZIP编码分别独立。新增 JSON 对照资料导出，保留资料版本、采用口径、关系和来源。
- `src/` 是前端编辑入口，`dist/` 是可重建成果，保留无需服务器的离线打开方式。旧构建脚本继续兼容。
- 当前36项自动检查通过，覆盖原功能及新模块边界。真实浏览器排版与操作验收尚未完成，本次浏览器工具禁止访问本地 `file://` 文件。PDF仍为图片页面。

## 第七版：渲染、分享与自动发布

- 时间轴、国家行和年份参考线分别维护。未变化的国家行复用原有DOM，排序移动节点；筛选或缩放只替换内容变化的节点。缓存每行显示输入与搜索结果，网页渲染不再深拷贝整份历史正文。
- 工具栏的“分享当前对照”和详情内的“分享此详情”可复制链接，包含所选国家、顺序、固定行、参考年、时间范围、缩放、分类、显示模式、搜索条件和当前详情。URL中的显式条件在本地阅读记录恢复后生效；跨屏幕按可见时间范围适配。
- 视图变化以防抖后的 `replaceState` 同步到Hash，不为每次滑动新增历史条目。支持手动修改Hash和浏览器前进后退；非法字段会被忽略。无Hash时继续恢复本地阅读位置。
- [GitHub Actions工作流](.github/workflows/site.yml) 在PR、`master`推送及手动运行时检查发布文件一致性、运行全部测试并构建；仅`master`推送或手动运行可发布`dist/`至Pages。启用方法见 [部署说明](docs/DEPLOYMENT.md)。工作流文件不代表已经上线。
- 当前45项自动检查通过，包含国家行节点复用、排序与筛选、分享链接恢复、详情分享、跨设备范围、浏览器历史和本地文件兼容。
