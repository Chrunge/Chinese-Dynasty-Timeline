# 周代列国 · 历史对照图

纯静态中文历史对照网页，覆盖周王室与17个主要诸侯国。打开 `dist/index.html` 即可使用；部署目录为 `dist`。

主要交互：横向拖动、纵向滚动、时代定位、缩放、国家筛选、国家/君主/人物/事件分类搜索、详情、同年列国对照及秦统一时期延伸。

## 数据

`dist/history.json` 是可直接编辑的结构化资料；`dist/data.js` 为浏览器使用的生成数据，同时合并 `dist/people.json` 中的独立人物简介与明确关联。编辑 JSON 后运行 `node sync-data.mjs` 同步。

纪年底表参考《史记》十二诸侯年表、六国年表与现代君主列表汇编。正文包含原典来源与采用口径说明。该版重大事件为精选；西周早期、晋终结、楚破越及部分即位纪年须继续校勘。不能将元年直接等同实际即位年份。未逐项核实的君主结局明确注明。

秦统一是秦诸侯国阶段的结束，不是秦王政统治的结束。卫国到前209年才终止，不在前221年截断为灭亡。

浏览器原生 WebMCP API 可用时注册 `compare_zhou_year`；不支持时不影响界面功能。

## 第二版交互与人物资料

支持全局36–160px行高、单国行高、320–1000px视窗高度、自动适配所选国家、展开对比，以及战国七雄一键对比。国家排序支持拖动和上移/下移，布局偏好保存在浏览器中。

点击君主可查看简要生平、关键臣子与将领的身份、关联关系、简介和原典来源。当前129个在位区间有专门生平简介，78个区间关联关键人物，共113位臣子与将领。其余区间显示纪年与记载摘要，明确标注资料不足。搜索支持已收录人物姓名。

`enrich-people.mjs`生成结构化人物数据及`dist/people.json`，再运行`node sync-data.mjs`同步浏览器数据。

## 第三版：对照研究

- 自动内容密度：低于2.4px/年显示国家存续与精选关键事件，2.4–7px/年显示君主与事件摘要，7px/年以上在足够宽度与行高下显示在位年份。可手动切换完整内容或概览。
- 点击事件高亮相关国家与当年在位君主；20条重点事件收录了明确关联的人物角色，其他事件保留待核实提示，不把全体臣子当成参与者。
- 纪年分较确定、推定、存在异说；君主详情将实际即位、元年、退位/传位、去世、身份转变分开。未核实日期不从条带端点推导。牧野、马陵、楚越及部分君主的异说可展开查看。
- 预设七雄、秦魏变法、晋楚争霸、鲁卫齐；可命名保存当前国家、顺序、固定行、行高与时间范围，支持组合JSON导出导入。浏览器保存最多30组。钉住国家后该行在纵向滚动中保持可见；在排序面板中只能在同一固定状态组内上/下移动。

更新生平资料后依次运行 `node enrich-people.mjs`、`node enrich-context.mjs`、`node sync-data.mjs`。`enrich-context.mjs`维护可信度、明确的生涯节点、关键事件与参与人物。

## 搜索与快速切换

七雄组合保留在右侧快速切换栏。搜索默认匹配名称、别称和明确的事件参与人物，按国家、君主、人物、事件分组；可勾选“同时搜索简介”，简介提及会单独标注。支持常用简繁体写法与已收录别称。搜索范围可选全站或当前所选国家，全站包含未选国家与秦统一时期。点击结果会打开对应详情并调整显示范围；未定位到具体年份的君主仅展示资料，不生成虚构的时间点。

## 详情返回

国家世系、君主、人物、事件和密集事件列表之间的跳转保留浏览路径。详情顶部的返回按钮始终可见，可逐级恢复上页内容、已展开的纪年说法与阅读位置；首层详情返回时间线或搜索结果，恢复搜索、筛选、缩放、参考年份及滚动位置。Esc同样逐级返回；关闭按钮或点击背景直接回到最初入口。“定位在位起点”和“查看图上联动”是主动跳转，保留目标年份与图上联动。

## 第四版：学习笔记

- 所有已收录臣子、将领姓名可点击，搜索、君主详情和事件人物统一进入独立资料页，显示生平、活动国家、主要事迹、关联君主与事件。已整理吴起、商鞅、孙膑、乐毅、伍子胥、管仲六人的顺序轨迹；不明确的年份不推算，出身、流亡与任职分开标注。
- 57条重点事件含背景、经过、结果、后续影响和主题关联，覆盖全部远景关键事件。其余事件使用相同结构，明确标出尚待补充的部分，同国邻近事件仅表示时间关联。`dist/research.json`维护人物轨迹及叙事摘要，运行`node sync-data.mjs`编入浏览器数据；原有史料生成脚本不覆盖此文件。
- `dist/study.js`自动保存时间范围、缩放、筛选、参考年份、搜索、国家布局和阅读位置，刷新后恢复；保存最近50条国家/君主/人物/事件浏览记录及详情滚动位置。详情中的临时联动不会覆盖进入前的主图阅读位置。只存结构化数据和条目ID，不存详情HTML；均保存在当前浏览器，可清空浏览历史。
- `dist/export.js`按当前显示国家与可见时间范围导出。时间范围可改，每张可选择100/150/300年或全范围；输出A4横向分页PDF或ZIP内的2400×1700 PNG图片。完整君主、事件、纪年异说、图例和来源另附文字索引，避开窄条文字挤压。图上与导出中的国家中断/复国分段显示，统一事件编号跨国对应；事件类别筛选保留，内容不受缩放密度和显示模式限制。文件在浏览器生成，不依赖外部CDN。PDF为高分辨率图片页面，适合阅读打印，文字不是可选中的PDF文本。
