# 周代列国 · 历史对照图

纯静态中文历史对照网页，覆盖周王室与17个主要诸侯国。打开 `dist/index.html` 即可使用；部署目录为 `dist`。

主要交互：横向拖动、纵向滚动、时代定位、缩放、国家筛选、君主/事件搜索、详情、同年列国对照及秦统一时期延伸。

## 数据

`dist/history.json` 是可直接编辑的结构化资料；`dist/data.js` 为浏览器使用的同内容副本。编辑 JSON 后运行 `node sync-data.mjs` 同步。

纪年底表参考《史记》十二诸侯年表、六国年表与现代君主列表汇编。正文包含原典来源与采用口径说明。该版重大事件为精选；西周早期、晋终结、楚破越及部分即位纪年须继续校勘。不能将元年直接等同实际即位年份。未逐项核实的君主结局明确注明。

秦统一是秦诸侯国阶段的结束，不是秦王政统治的结束。卫国到前209年才终止，不在前221年截断为灭亡。

浏览器原生 WebMCP API 可用时注册 `compare_zhou_year`；不支持时不影响界面功能。

## 第二版交互与人物资料

支持全局36–160px行高、单国行高、320–1000px视窗高度、自动适配所选国家、展开对比，以及战国七雄一键对比。国家排序支持拖动和上移/下移，布局偏好保存在浏览器中。

点击君主可查看简要生平、关键臣子与将领的身份、关联关系、简介和原典来源。当前129个在位区间有专门生平简介，78个区间关联关键人物，共113位臣子与将领。其余区间显示纪年与记载摘要，明确标注资料不足。搜索支持已收录人物姓名。

`enrich-people.mjs`生成结构化人物数据及`dist/people.json`，再运行`node sync-data.mjs`同步浏览器数据。
